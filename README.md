# PROXITI | Central Técnica

Painel privado da PROXITI para administradores e técnicos parceiros.

**Etapa inicial:** autenticação gerenciada por Supabase Auth, sem cadastro público, com perfis e permissões no banco de dados. O frontend será publicado no GitHub Pages. As credenciais e informações pessoais nunca devem ser enviadas ao repositório.

A configuração de autenticação e as instruções de publicação acompanham o código da primeira versão.
